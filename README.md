## Архитектура агента
Приложение использует **3-шаговый агентный цикл**:

1. **EDA-агент** - проводит первичный разведочный анализ данных:
   - анализирует структуру и качество данных
   - вычисляет базовые статистики
   - генерирует и выполняет код для визуализации

2. **Агент анализа запроса** - обрабатывает пользовательский запрос:
   - использует результаты EDA
   - строит дополнительные графики при необходимости
   - формирует детальный ответ

3. **Агент итоговых выводов** - синтезирует результаты:
   - объединяет выводы из предыдущих шагов
   - формулирует рекомендации
## Безопасность
1. защита от prompt injection - фильтрация опасных слов в запросе пользователя
2. безопасное выполнение кода - блокировка опасных модулей (os.system, subprocess, eval, exec)
## Запуск проекта
### 1. клонировать репозиторий
```bash
git clone https://github.com/SevaAlieva/3taska.git
```
### 2. создать виртуальное окружение
```bash
    python -m venv venv
```
### 3. установить зависимости
```bash
pip install -r requirements.txt
```
### 4. настроить API ключ 
    создать файл .env:

        OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
### 5. запустить приложение
```bash
streamlit run app.py
```
### Как пользоваться
#### 1. загрузить датасет - CSV или Excel файл с данными
#### 2. написать запрос - что нужно проанализировать (или оставить пустым для полного анализа)
#### 3. нажать "Запустить анализ" - агент сам напишет код, выполнит его и вернет результат
